# Changelog

## 1.0.1

- Added a Nexus Mods update key, so SMAPI can check Nexus as well as GitHub for new versions.

## 1.0.0

First release.

- The ledger opens each morning and with **L**. It has four sections:
  - Crops ready to harvest
  - Upcoming birthdays, with gift suggestions from your bag
  - Bundle items you're carrying
  - Crops that won't survive the season change
- You can collapse sections and scroll. The panel resizes to fit its contents.
- The `ledger` console command prints the same information to the SMAPI console.
- Optional support for Generic Mod Config Menu.
